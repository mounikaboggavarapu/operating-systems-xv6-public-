2. Generally, wc command gives the count of number of lines, number of words and number of bytes in a file. 
Running wc command on itself like wc wc, it will treat wc as a file name and gives the count of lines, words and bytes in wc file. 
$ wc wc
73 558 15888 wc

	"np" is the local variable name for the pointer PCB of the child process because allocproc() allocates,
	so, np is the struct proc pointer that points to the new child process. 
	"curproc" is the local variable name for the pointer PCB of the parent process because it is set by calling myproc().
